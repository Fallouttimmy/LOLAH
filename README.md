# LOLAH 🤖

LOLAH is a modular, local-first AI assistant designed to evolve into a personal intelligent system with memory, voice, vision, and learning capabilities.

## Vision
LOLAH aims to function like a JARVIS-style assistant that can:
- Hold natural conversations
- Remember facts using a knowledge graph
- Learn from user interactions
- Use voice (STT + TTS)
- Support vision (camera input)
- Work offline with a local model
- Expand via plugins

## Architecture (Phase 1)
- Core Assistant Engine
- Memory System (Knowledge Graph + Database)
- Speech System (Wake word, STT, TTS)
- AI Brain (LLM integration + reasoning layer)
- Learning System (web + user input)
- Vision System (future phase)
